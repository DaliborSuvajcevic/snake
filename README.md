# Snake · The Golden Circle

Snake igra kao web aplikacija (PWA), optimizovana za telefon.

- Live: https://daliborsuvajcevic.github.io/snake/
- Instalacija na iPhone: Safari → Share → Add to Home Screen
- Instalacija na Android: Chrome → meni → Install app / Add to Home screen

Kontrole: swipe po tabli, strelice ispod table, ili tastatura (strelice / WASD, SPACE pauza).

Napomena: posle izmene fajlova povećaj `CACHE` verziju u `sw.js`.
